  specs {OPTIONS}

    The Scalable Photonic Event-driven Circuit Simulator.

  OPTIONS:

      -f[circuit...],
      --file=[circuit...]               Simulate from circuit file
      -R[set_timescale],
      --resolution=[set_timescale]      Set the engine timescale (as
                                        log10(timestep/1s))(0: seconds, -3: ms,
                                        -6:µs, ..., -15: fs)
      -m[set_simulator_mode],
      --mode=[set_simulator_mode]       Set simulator mode. Possible values:
                                         - time-domain, event-driven, td
                                        (default)
                                         - sampled-time
                                         - frequency-domain, fd
      -T, --run-manual-test             Run manual test function
      -o[set_tracefile],
      --output=[set_tracefile]          Set the default trace file
      --format=[format...]              Output format of the traces: vcd
                                        (default), csv or npz (tables of the
                                        probed signals: time, signal,
                                        wavelength, power, complex field),
                                        written as <output>.vcd/.csv/.npz;
                                        repeat it to write several; netlists
                                        only
      --no-trace                        Write no trace file and no run manifest
                                        (the probes and .save targets are not
                                        traced); netlists only
      --json=[export_json]              Export json of completed circuit to file
      --version                         Output version information and exit
      --print-manifest                  Print the run manifest (version, seed,
                                        command line, netlist file hashes) to
                                        stdout. It is also written next to the
                                        default trace file, as
                                        <trace>.manifest.json
      -n, --dryrun                      Do not run simulation directives
      --reltol=[set_reltol]             Set the value of the relative tolerance
                                        parameter for field
      --abstol=[set_abstol]             Set the value of the absolute tolerance
                                        parameter for field
      --seed=[set_seed]                 Set the master seed of the random
                                        streams (decimal integer, 0 to 2^64-1,
                                        default 0); overrides .options seed
      --param=[name=value...]           Set the netlist parameter <name>, parsed
                                        as in .param name=value; overrides the
                                        netlist's .param/.assign of the same
                                        name (repeatable)
      --run=[K]                         Run only run K of the netlist's
                                        .step/.mc plan, in this process, with
                                        the outputs of a single run (trace,
                                        tables, manifest, stdout): each run is
                                        reproducible on its own
      -j[N], --jobs=[N]                 Runs of a .step/.mc plan simulated at
                                        the same time, one process each (default
                                        1)
      --overwrite                       Replace the run table <output>.runs/ of
                                        a .step/.mc plan instead of resuming it
      --maxiter=[set_maxiter]           Set the maximum number of iterations
                                        (delta cycles) of the .op/.dc fixed
                                        point, per operating point or sweep
                                        point (decimal integer, default 1000000,
                                        0: no limit); overrides .options maxiter
      --stats=[sections]                Write run statistics: counters of the
                                        optical output ports (values scheduled,
                                        coalesced, processed, emitted,
                                        suppressed by abstol/reltol/snap,
                                        pending entries, last emission) and the
                                        wall time, as JSON in
                                        <output>.stats.json. Sections: summary
                                        (default), ports (one row per output
                                        port), devices (per device type),
                                        comma-separated (--stats=ports,devices)
      --stats-file=[file]               Write the run statistics to this file
                                        instead (implies --stats); without it,
                                        --no-trace or -o "" print them to stdout
      --print-stats                     Also print the run statistics (JSON) to
                                        stdout (implies --stats)
      --progress=[seconds]              Print a progress line (wall time,
                                        simulated time, delta cycles) on stderr
                                        every <seconds> of wall-clock time
                                        (default 1); it never changes the
                                        simulation; netlists only
      --max-events=[set_max_events]     Expert option: stop the run once the
                                        optical output ports have processed this
                                        many pending entries (decimal integer,
                                        default 0: no cap); a .tran ends there
                                        with a warning, an .op/.dc stops with an
                                        error; overrides .options maxevents
      --nrings_crow=[set_nrings_crow]   temporary
      --vci, --verbose_ci               Print components detail before starting
                                        simulation
      -p, --list-testbenches            List available testbenches
      -t[test_name],
      --testbench=[test_name]           Run the specified testbench (use -p to
                                        list available testbenches)
      -h, --help                        Display this help menu
